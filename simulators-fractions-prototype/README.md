# Fractions Simulator Prototype

Run the prototype locally:

```bash
cd simulators-fractions-prototype
pnpm install
pnpm dev
```

Features:
- Interactive fraction visualization (pie and bar)
- Sliders to change numerator and denominator
- KaTeX-rendered equation panel with equivalent fractions

This is a small scaffold to iterate quickly — I can add drag-to-shade, student tracking, and export next.
